写真の中のものを、**手動操作や確認済みの自動検出候補で数える**ための単一HTMLアプリです。点・矩形のマーカーで「どこまで数えたか」を残し、迷った対象は要確認にして後から見直せます。選択した画像はアプリからサーバーへアップロードされません。

同じ対象を何枚も検査する場合は、見本を囲んで **この見本を固定** を押します。種類ごとに見本を保持し、別の画像では囲み直さず **検出する** を押せます。結果を確認後、**追加して次を検出** で一覧順に進めます。固定見本は途中保存・閲覧HTMLに含まれ、元の写真を削除しても残ります。保存済みの画像上で修正するときは **見本を追加・編集**、別の写真で作り直すときは **固定を解除** を使います。画像ごとの結果確認は必要です。

## 主な機能

- **自分で数えるから、数えた場所が分かる** — 点をタップするか、対象を矩形で囲むと1個としてカウントします。
- **数えた後でも修正できる** — 点の移動、矩形の移動・四隅リサイズ、種類変更、削除、Undo / Redoに対応します。ポインター操作が中断された場合は追加を破棄し、移動・サイズ変更を元に戻します。Redo履歴も維持され、ピンチ操作へ切り替えた場合も未確定のマーカー編集は取り消されます。
- **確認しながら不要な結果をまとめて削除** — 確認モードではマーカーを追加・移動せずに選択できます。1件ずつ、複数タップ、範囲で選んで削除し、1回のUndoで削除全体を戻せます。
- **画像を見たまま種類を切り替え** — Canvas下端の半透明ドックから1タップで切替。PCでは数字キー `1`〜`9` でも切り替えられます。邪魔なときはドックを小さくできます。
- **迷った対象は「要確認」へ** — 種類やカウント数を変えずに要確認フラグを付け、後から見直せます。要確認が残っている画像は完了にできません。
- **複数画像を順番に処理** — 状態でサムネイルを絞り込み、該当する写真だけを順に確認できます。写真数は作業全体の進捗を表示します。**確認完了して次へ** で写真を確認済み・完了にして、次の未完了へ進めます。
- **見にくい画像を非破壊で補正** — 明るさ、コントラスト、白黒、90°回転を画像を見ながら調整でき、元画像は書き換えません。
- **カメラで撮影してそのまま作業** — 撮影後に確認し、撮り直し・採用・採用して次を撮影を選べます。
- **作業の続き・持ち運びに対応** — このブラウザー内への自動保存に加え、**保存・書き出し → 作業をHTMLに保存** で写真・固定見本・マーカー・確認状況をファイルに残せます。**作業を開く** で編集を再開できます。
- **使いやすい形で結果を書き出し** — 作業HTMLを直接開くと、読み取り専用で結果を確認できます。`markers.csv` / `summary.csv` と任意のマーカー付きJPEGをまとめたZIPも保存できます。
- **閲覧HTMLからも結果を保存** — 画像切替、表示ON/OFF、画像情報・コメント確認、JPEG保存、CSV+JPEG ZIP保存に対応。画像カウンターへ読み戻せば編集を再開できます。
- **完全ローカルのランタイム** — アカウント、分析タグ、外部フォント、ランタイムCDN、画像アップロードはありません。CSPの `connect-src 'none'` で実行時通信を禁止しています。

## 自動検出を試す

固定した見本は **見本を追加・編集** から、保存済みの元画像上で修正できます。**追加** では新しい枠を描き、**選択・修正** では画像の枠または見本一覧の番号から対象を選びます。選んだ枠の内側をドラッグして移動、四隅のハンドルでサイズ変更できます。割合の数値を入力し、**選んだ見本に反映** で細かく調整することもできます。枠は画像内に収まり、**選んだ見本を削除** は選択した1個だけを消します。未選択時は削除できません。固定前の見本にも同じ操作を使えます。

小さな枠は、プレビューのピンチ操作または **− / +** で1〜8倍に拡大して調整できます。2本指を同じ方向へ動かすと表示位置を移動でき、**表示を移動** を選ぶと1本指のドラッグでも移動できます。**全体表示** と倍率操作はプレビューのすぐそばにあり、四隅のハンドルは拡大しても画面上の大きさを保ちます。**追加** または **選択・修正** を選ぶと表示移動を終了し、倍率と位置は維持します。画面を閉じるか表示元が変わるとリセットします。拡大は表示だけに作用し、保存する枠・元画像・検出入力は変わりません。

固定見本への修正は **見本の変更を保存** まで確定せず、保存後は1回の **Undo** で元の見本に戻せます。**変更を取り消す** または画面を閉じると保存済みの見本を維持します。ポインター操作の中断や2本目の指の接触では、未確定の追加・移動・サイズ変更を破棄します。ピンチへ移っても選択中の見本は維持し、残った指を離しても破棄した編集は確定しません。見本の編集でカウントは変わりません。別の写真で作り直す場合は **固定を解除** してください。点線は追加済みのカウントマーカーで、初期状態では非表示です。同じ位置の検出結果は二重カウント防止のため追加できません。

**検出** パネルから **見本・検出設定** を開き、選択中の種類に見本を固定すると、**この写真を検出**／**全写真を検出** が使えます。この写真の検出はCanvasの近くからも実行でき、全写真の検出は検出パネルにあります。全写真には完了済みの写真も含みます。初期設定の **追加検出** は既存マーカーを残し、**未確認の自動結果を置換** は選択中の種類のうち、人が確認・編集していない自動マーカーだけを更新します。新しい結果は **要確認** として追加し、残すマーカーとの重複は除外します。

手動、確認済み、編集済み、別の種類のマーカーは置換しません。dev.10より前の結果も、自動追加されたものか確実に区別できないため残します。移動・サイズ変更・種類変更・要確認の切り替えをしたマーカーは、再び要確認にしても置換対象に戻りません。写真ごとの変更は検出成功後に反映します。正常な0件の結果では対象の古い結果を削除できますが、失敗・中断・結果の一部しか得られなかった場合は維持します。**停止** しても処理済みの写真は残り、1回の **Undo** で今回の処理全体を戻せます。

メイン画面からの検出では、モデルと固定見本を最初に一度準備し、同じ実行内の写真に使い回します。写真ごとに同じ準備を繰り返さず、結果には準備を含む所要時間を表示します。終了・停止・実行エラー時には今回の処理用メモリーを解放し、次の実行は新しく準備します。モデルや検出設定は変えていません。

検出が成功した写真は、0件や重複のみでも確認が必要です。1枚以上の検出が成功した実行の終了後は、途中で停止した場合もメイン画面が **確認** モードになります。検出画面から候補を追加した後も同じです。確認後は **確認完了して次へ** で要確認を解除し、写真を完了にして次の未完了へ進めます。末尾では先頭へ戻って探し、すべて完了したら現在の写真に留まります。**要確認を解除** は確認だけを行い、完了状態を変えません。どちらもUndoで戻せます。

![自動検出で候補を確認する画面](assets/auto-detection.jpg)

1. 追加先の種類を選び、**検出** パネルから **見本・検出設定** を開きます。
2. 内蔵モデルをそのまま使えます。標準（CPU）・FP32が初期設定です。必要な場合だけ **詳細設定・モデル変更** で対応する外部モデルを選択します。
3. **追加** で見本を1個以上囲むか、**数値で見本を囲む** から上下左右の割合を入力します。修正するときは **選択・修正** に切り替え、画像の枠または一覧の番号で選んで、移動・サイズ変更・削除・数値の反映を行います。番号ボタンと数値入力はキーボードでも使えます。
4. **検出する** を押し、不要な候補をクリックまたは一覧のチェックで外します。プレビュー中はカウントが変わりません。
5. **候補をマーカーに追加** で確定します。非表示や別種類も含めた既存マーカーとの重複は除外され、1回のUndoで全件戻せます。

キャンセルまたは画面を閉じると推論を中断します。モデルはページを閉じるまでの保持で、途中保存・出力には入りません。検出は元の写真を使用し、明るさ・コントラストの表示補正は使いません。

別のページへ移動した場合も検出を中断し、戻った画面から再実行できます。新しい検出・見本編集機能のAndroid Chrome実機確認と、ファイル直接起動の確認は未実施です。[実機確認手順](docs/ANDROID_FILE_TEST.md) に検証項目をまとめています。

## 検出範囲と絞り込み一覧の検出

**写真** パネルの絞り込みの横にある **一覧のN枚を検出** は、開始時に該当する写真だけを順番に処理します。検出によって写真の状態が変わっても、今回の対象一覧は変わりません。**全写真を検出** は引き続き作業全体を対象にします。どちらも停止でき、1回のUndoで今回処理した分を戻せます。

写真ごとに検出範囲の矩形を描くか数値で指定して保存できます。キャンセルは未保存の変更を破棄します。範囲を解除するには「写真全体」を選んでから「範囲を保存」を押します。保存した変更は写真を未完了に戻しますが、既存マーカーは変えず、Undoで戻せます。範囲は途中保存・作業HTMLの読み戻しや写真圧縮後も保持します。以前の作業は写真全体が対象です。

推論は写真全体に対して行い、中心が指定範囲内（境界を含む）にある候補だけを採用します。切り抜き推論ではなく、小さい対象の精度改善や高速化を保証する機能ではありません。**未確認の自動結果を置換** でも、範囲外の自動マーカーと従来の保護対象は残します。集計・CSV・JPEGは範囲に関係なくすべてのマーカーを含みます。

## 写真を中心にした作業画面

すべてのモードで写真を主な作業場所にし、補助パネルを **写真・検出・作業** で切り替えます。写真パネルには一覧・絞り込み・写真の追加など、検出パネルには見本・範囲・検出設定、作業パネルには集計・種類・表示・ブラウザー保存の設定をまとめています。この写真の検出、前後移動、モード切り替え、保存は写真の近くから使えます。

PCでは右側のパネルだけをスクロールできます。狭い画面では **写真・設定** で写真の作業領域を一時的にパネルへ切り替え、**写真に戻る** で戻します。確認モードの選択操作と **確認完了して次へ** はCanvasの近くに置き、スマホ下部にはUndo・Redo・前後の写真・保存を表示します。ほかのモードの下部操作はUndo・Redo・追加・種類・保存です。パネルの表示状態は一時的で、別の作業を開くとリセットします。新しい作業画面のAndroid実機確認は未実施です。

## 使い方

1. JPG / JPEG / PNG / WebP画像を1枚以上追加するか、カメラで撮影します。
2. カウントを追加する **点 / 矩形**、結果を確認する **確認**、表示位置を動かす **移動** から選びます。
3. Canvas下端の半透明ドックから、現在数える種類を選びます。PCでは `1`〜`9` キーでも切り替えられます。
4. 点モードでは対象を1回タップ / クリック、矩形モードでは対象を囲むようにドラッグします。
5. 確認モードで既存マーカーを選び、確認・削除します。位置や矩形の大きさを直す場合は **単一** でマーカーを選んで **編集** を押すと、移動や四隅リサイズができます。
6. 確認モードの単一選択では、旗ボタンで **要確認** を付けたり解除したりできます。確認モードのまま操作でき、自動検出は新しいマーカーが0件の場合も写真を確認します。
7. Canvas右上の「完了」横にあるメモボタンから画像メモを追加できます。PCではCanvas内のメモパネルをドラッグ移動でき、スマホではCanvas直下に表示します。
8. 写真を確認したら **確認完了して次へ** を押します。**写真** パネルで状態を絞り込み、前へ・次へ / 左右キーで該当する写真を切り替えることもできます。
9. **保存・書き出し**（スマホ下部は **保存**）を開き、ファイル名を入力して **作業をHTMLに保存**、または集計ZIPを保存します。「マーカー付きJPEGを含める」をオフにするとCSV 2ファイルだけを書き出せます。

狭い画面でも右上のEN / JAとヘルプを使えます。「使い方と注意事項」は3つの手順と、AI結果の確認・保存・プライバシー・読み込み時間についての短い注意事項から始まります。補足の操作と保存の説明は折りたたみ、ライセンス・ソースコード・ビルド情報はそのまま残しています。見出しを固定して本文をスクロールできます。スマホ幅の開始画面は写真選択・カメラのボタンを幅いっぱいに配置し、従来どおりビルド情報とフッターは非表示です。広い画面ではビルド情報を確認できます。

### キーボード操作

| ショートカット | 操作 |
| --- | --- |
| `1`〜`9` | 対応するカウント種類へ切り替え |
| `←` / `→` | 絞り込みに該当する前 / 次の写真へ移動 |
| `Ctrl` / `⌘` + `Z` | 元に戻す |

## カウントと要確認

### 点 / 矩形マーカー

通常は点マーカーが手早く使えます。対象が密集している、小さい、輪郭を残した方が後から確認しやすい場合は矩形が便利です。マーカー上の番号は**種類ごとに1から**振られ、画像全体・プロジェクト全体の合計は別に保持します。

### 確認と選択したマーカーの削除

**確認** モードは **単一** で始まり、空白をタップしてもカウントを追加しません。単一・**複数** でドラッグすると、マーカーを動かさず写真の表示位置を移動します。単一で選んだマーカーには要確認の切り替えと **編集** を表示します。要確認は確認モードのまま切り替えられます。位置や大きさを直すときは編集を押すと、選択を維持して点・矩形モードへ切り替わります。複数・**範囲** では、1件だけ選んだ場合もこの操作欄を表示しません。

- **単一**：表示中のマーカーを1件選びます。
- **複数**：タップするたびに、そのマーカーの選択を追加・解除します。
- **範囲**：ドラッグした範囲に中心が入る表示中のマーカーを追加選択します。このモードでは2本指で写真を移動・拡大できます。

選択件数を確認し、やり直す場合は **選択を解除**、消す場合は **選択を削除** を押します。現在の写真の選択したマーカーだけを削除し、写真を未完了に戻します。1回のUndoで削除全体を戻せます。ほかの写真や検出結果の確認記録は変わらないため、不要な枠をすべて消しても写真の確認は別に必要です。

非表示のマーカーは選択できません。選択は一時的な状態で、写真・モードの変更、マーカーの非表示、Undo/Redo、検出開始時などに解除または整理します。範囲ドラッグを中断したりピンチへ移ったりした場合は、未確定の選択だけを破棄します。選択状態は作業ファイルに含めず、削除とそのUndo/Redoの結果は自動保存します。

### 要確認

**要確認**は通常マーカーに重ねて付けるフラグです。別の種類にはならず、カウント数も変わりません。要確認中は黄色い `!` が付き、画像一覧や集計でも残数を確認できます。

写真には検出結果を確認したかどうかも記録します。そのため、0件や重複のみの検出でも、写真を確認するまでは要確認マーカー0件の **要確認** 状態になります。通常の **完了** ボタンは、マーカーと検出結果の両方を確認するまで使えません。

サムネイルと現在の写真の欄には **未検出・作業中・要確認・完了** を表示し、集計には状態ごとの写真数を表示します。要確認は完了より優先します。手動で数えた写真は作業中になり、未作業の旧プロジェクトを検出済みと見なすことはありません。確認状態は途中保存や閲覧HTMLの読み戻しでも保持します。

### 状態で写真を絞り込む

サムネイル直上の **写真一覧** で **すべて・未検出・作業中・要確認・完了** を選べます。各選択肢の写真数は常に作業全体から数え、該当枚数と全体の枚数も表示します。**すべて表示** ですべてに戻ります。検出結果が未確認の写真は、要確認マーカーが0件でも要確認に含まれます。

現在の写真が条件から外れてもCanvasの表示は維持し、**表示中の写真は絞り込み対象外です** と案内します。前へ・次へ / `←`・`→` は該当する写真だけを元の順番で移動し、端で止まります。現在の写真が対象外なら、その前後で最も近い該当写真へ移動します。該当写真が0枚なら **条件に合う写真がありません** と表示し、前後の移動は使えません。

同じ作業内では編集・確認・Undo/Redo・言語変更後も絞り込みを維持します。新しい作業、作業を開く、途中保存の復元、ページ再読み込みではすべてに戻ります。絞り込みでカウントや保存データは変わりません。集計・書き出し・**全写真を検出**・**次の未完了へ**・**確認完了して次へ**・検出画面から次の写真へ進む操作は引き続き作業全体を対象とするため、これらの移動操作では絞り込み対象外の写真を開くことがあります。

### 画像の表示補正

暗い写真や見づらい写真では「画像の表示補正」を開き、画像を見たまま以下を調整できます。

- 明るさ
- コントラスト
- 白黒の強さ
- 90°回転

元画像自体は上書きしません。

## 作業の保存・再開

**保存・書き出し → 作業をHTMLに保存** で、写真・固定見本・マーカー・確認状況を1つのファイルに残せます。保存ボタンを押した時点の内容とファイル名で保存します。HTMLを直接開くと、**結果を確認・共有するための読み取り専用ビュワー**になります。作業データを含みますが、編集アプリや検出モデルは含みません。

以下を確認・操作できます。

- プロジェクト全体の合計、完了画像数、要確認件数
- 種類別集計
- サムネイル / 前へ・次へ / `←`・`→` による画像移動
- 点・矩形マーカーと種類ごとの番号
- マーカー / 番号 / 種類別表示のON/OFF
- ファイル名、撮影日時と取得元、画像サイズ、元形式/容量、完了状態、件数、要確認件数を整理した画像情報
- SVGアイコン付きの独立した **「コメント」** 欄
- 現在画像のマーカー付きJPEG保存
- CSV + 全画像JPEGのZIP保存

閲覧HTML内の保存操作には確認ダイアログが入ります。

続きを編集する場合は、このアプリの開始画面または **保存・書き出し** 画面の **作業を開く** でHTMLを選びます。以前の閲覧HTMLも開けます。別の作業が開いている場合は、ファイルを検証した後、現在の作業とブラウザー内の自動保存を置き換えるか確認します。現在の作業を残す場合はキャンセルし、先にHTMLへ保存してください。不正なファイルでは現在の作業を変更しません。

## 出力ファイル

### CSV + 任意のマーカー付き画像ZIP

編集画面の「マーカー付きJPEGを含める」は初期状態でオンです。オフにすると画像の読み込み・描画を行わず、`markers.csv` と `summary.csv` だけをZIPに保存します。選択はページを再読み込みするまで保持され、作業データには保存されません。CSVの内容と編集可能なZIPファイル名はどちらのモードでも共通です。閲覧HTMLからのZIP保存には従来どおりJPEGも含まれます。

初期設定の内容:

```text
result.zip
├─ markers.csv
├─ summary.csv
└─ images/
   ├─ 01-counted-....jpg
   └─ 02-counted-....jpg
```

`markers.csv` には画像情報、撮影日時 (`image_captured_at`) と日時の取得元 (`capture_time_source`)、表示補正、点/矩形、要確認状態、種類内番号、種類、正規化座標、px座標、矩形サイズなどを保存します。

`summary.csv` には画像・種類・プロジェクト単位の件数と `review_count` を保存します。

### 作業HTMLの画像圧縮

**保存する写真を圧縮** をオンにすると、写真をWebPに変換してファイルサイズを減らせます。次回の検査でも細部を保ちたいときはオフにしてください。固定見本の画像は圧縮しません。CSV + 画像ZIPのマーカー付き画像はJPEGです。

## カメラと撮影日時

画像情報の撮影日時は、次の順で取得します。

1. JPEGにEXIF撮影日時がある場合はEXIFを優先
2. EXIF撮影日時がない場合は選択したファイルの日時
3. アプリ内カメラで撮影した場合は実際の撮影時刻

撮影日時と日時の取得元は、閲覧HTMLとCSVにも保持されます。

## 途中保存と容量

新しい写真・サンプル・閲覧HTMLを正常に読み込むと、前回の作業の復元案内は閉じます。ファイル選択をキャンセルした場合や読み込みに失敗した場合は、保存済みの作業を引き続き復元できます。復元案内の集計、操作の読み上げ名、ツールチップも日本語／英語の切り替えに追従します。

対応ブラウザーではプロジェクトをIndexedDBへ自動保存します。このコピーは、このブラウザー・このページ内の続き用です。端末変更では引き継がれず、ブラウザーのデータ削除で失われる場合があります。大切な作業はHTMLでも保存してください。画面から以下を確認できます。

- 現在の作業データ容量
- 途中保存容量
- ブラウザーが提供する場合はストレージ空き容量

途中保存用の画像コピーだけをWebPへ変換して容量を減らすこともできます。論理的な画像サイズやマーカー座標は維持されます。

## GitHub Pagesで公開する

このリポジトリには、単一HTMLをビルドして `dist/` をGitHub Pagesへ公開するワークフローが含まれています。

1. リポジトリ名を `htmlapps-image-counter-ex` としてGitHubへプッシュします。
2. **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選択します。
3. `main` へプッシュするか、Actionsから **Deploy standalone app to GitHub Pages** を手動実行します。
4. 成功後、`https://ttomohisa.github.io/htmlapps-image-counter-ex/` で利用できます。

公開前にリポジトリ検証が実行されます。Pagesがまだ有効でない場合でもビルドは行われ、ActionsのSummaryに初回設定手順が表示されます。

## 開発とビルド

既定のビルドでは、配布用の `image-counter.html` も更新します。ソースの変更と一緒にこのファイルをコミットしてください。`-OutputPath` を指定したビルドはこのファイルを変更しません。Node.js 24 が利用できる環境で `scripts/check-repository.ps1` を実行すると、配布ファイルの同期とカメラの回帰テストを検証します。古い配布ファイルは上書きせず、エラーとして報告します。

生成済み `dist/index.html` は直接編集せず、`src/index.template.html` を変更してください。

```text
.
├─ src/index.template.html       # アプリ本体のテンプレート
├─ app.config.json               # アプリ名・バージョン・ビルド設定
├─ dependencies.json             # 内包依存一覧（固定ORT資産）
├─ build-standalone.bat          # Windows用ビルド入口
├─ build-standalone.ps1          # 単一HTMLビルダー
├─ scripts/                      # 検証・自己展開版生成
├─ assets/                       # favicon / README用スクリーンショット
├─ dist/index.html               # 生成済み単一HTML
└─ .github/workflows/
   ├─ build-standalone.yml       # PR / 手動のビルド検証
   └─ deploy-pages.yml           # GitHub Pages公開
```

ビルド時には単一HTMLの検証、ビルド情報の生成、自己展開版の生成が行われます。

## プライバシーと通信防止

生成されたHTMLは、選択した画像を端末の外へ出さない構成です。

- Content Security Policyに `connect-src 'none'` を指定
- ランタイムCDN・外部フォントなし
- 分析タグ・テレメトリなし
- アカウント・バックエンドなし
- 画像やマーカーデータをアプリからアップロードしない
- カメラ映像はブラウザーのローカルメディアAPIで処理

GitHub Pages版では最初のHTML取得だけは通信します。ネットワークを完全に切って利用する場合は、`dist/index.html` をローカルで開いてください。

## 制限事項

- 自動検出は開発段階です。誤検出・見落としを人が確認してください。固定見本で現在の写真、または全写真を順番に検出できます。タイル分割は未実装です。
- 現在のUIでは1プロジェクト最大30枚です。
- 1画像35MB超は読み込まず、プロジェクト全体にも220MBの元画像データ上限ガードがあります。
- 高解像度画像を多数扱うと、端末メモリやブラウザーストレージを多く消費します。
- ライブカメラはブラウザー権限やSecure Contextの条件に依存します。利用できない場合は端末カメラ / ファイル入力へフォールバックします。
- EXIF撮影日時の読み取りは主にJPEGを対象とし、その他の形式では通常ファイル日時を使用します。
- v1.0.0ではExcel (`.xlsx`) 出力に対応していません。

### 読み込みとCSVの安全対策

閲覧HTMLは対応するプロジェクト形式と埋め込み画像を検証してから作業を置き換えます。SVG・外部URLの画像、不正データ、30枚超、画像の実データ35 MiB超、画像＋メタデータ合計220 MiB超は読み込めません。HTML自体は符号化による増加を考慮して読み取り前に661 MiBを上限とします。上限内でもブラウザーのメモリー不足になる場合があります。以前の上限超過・SVG入りの書き出しは縮小・変換が必要です。

編集画面・閲覧HTMLのCSVは、数式として扱われる可能性がある文字列に先頭アポストロフィを付けます。数値は数値のまま、プロジェクト内の元の文字列も変更しません。表計算ソフトによってはアポストロフィが表示されます。信頼できない文字列からこの保護を削除しないでください。
